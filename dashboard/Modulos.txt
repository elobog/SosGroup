Componente Solicitud:
Objetivo principal, gestionar las solicitudes de personal externo por cliente y por perfil de cargo. 
Usarios que interactúan: 
a) Supervisor. Empelado de SOSGroup responsable en terreno del personal externo que SOS group provee a sus clientes (empresas que requieren personal temporal por tipo de cargo y/o Faena). Un supervisor puede atender varios clientes.
b) Reclutador. Empelado de SOSGroup responsable de ejecutar la solicitud de personal de una empresas especifica en base a un perfil de cargo definido. Cada reclutador tiene bajo su gestión una o mas empresas. Cada empresa puede tener 1 o mas solicitudes activas o en ejecución. 

Acciones:
Nueva Solicitud
Nuevo cliente
Nuevo Perfil de cargo
Ver/Modificar Solicitud
Ver/Modificar Cliente
Ver/Modificar Perfil de cargo
Asignar Reclutador a Cliente
Asignar Supervisor a Cliente

Flujo. 
Supervisor crea nueva solicitud o requiere mas personal de una solicitud existente.
Reclutador recibe aviso de nueva solicitud o requerimiento de mas personal de una solicitud.
Reclutador inicia el proceso de solicitud

Modulo Postulación 
Objetivo: Es un panel de acceso publico que le permite a cualquier persona postular a los cargos(solicitudes), a través de este modulo el psotulante podra ver que solicitudes estan disponible, podra participar y podra enviar los datos y completar las tareas de preselección en la medida que vaya avanzando en el proceso.
el panel debe ser autoresponsivo y debe funcionar en telefonos moviles.
es de acceso publico

a) postulantes

Acciones
Ver y seleccionar una solicitud para postular.
Inscripcion inicial. El sistema le pide nombre, telefono y correo. 
Verificacion de postulante. El sistema verifica telefono y correo. si existe, le manda mail con codigo para acceder. Si no existe le pérmite avanzar
Aceptación de politicas de uso de informacion personal, luego de ingresar los datos el sistema le pide que acepte las politicas de uso de datos personales. Mail a su correo el cual debe aceptar con un link-token para aceptar la politica.
Con la aceptacion se activa la cuenta.
Nueva postulación. si el candidato existe, y postula a una nueva solicitud, el sistema le envia correo para que vuelva a aceptar las politicas de uso de datos personales. 
Selecciona Solicitud para postular.
Carga informacion en un formulario con datos del psotulante
Upload de documentos (PDF o Archivo Imagen), Datos Documento de identidad, CV, Certificado Antecedentes, Certificado AFP, Certificado Isapre/fonasa.
Postular a solicitud.
Contestar Test a través de PIA (cuando reclutador lo habilite) 
Enviar mensaje por solicitud al reclutador. .
